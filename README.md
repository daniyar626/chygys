# CQA — оценка качества диалогов · команда Chygys

Прототип для хакатона Freedom Broker CQA. Система оценивает работу оператора поддержки в чатах и звонках на русском, казахском и английском по официальному «Чек-листу качества чатов»: баллы, обоснование и реплика-доказательство по каждому критерию, итог с перераспределением веса N/A и отдельный флаг грубых ошибок. Оценку можно оспорить: проверяющий подтверждает или меняет её, итог пересчитывается.

**Команда:** Chygys

## Запуск

Нужен Node.js 22+.

```bash
npm install
cp .env.example .env    # Windows: copy .env.example .env
npm start               # http://localhost:3000
```

В `.env` укажите:
- `ANTHROPIC_API_KEY` — ключ для оценки;
- `GEMINI_API_KEY` — ключ для распознавания записей звонков;
- `CQA_API_URL` — ссылку GET из задания без `&group_id=...`.

Тесты: `npm test`.

## Как работать

1. **Диалоги** — вверху выберите набор (DEV, FBroker, Swap) или загрузите новый по `group_id`. «Оценить неоценённые» запускает оценку всего набора. Фильтры: язык, канал, только с грубыми ошибками.
2. **Карточка диалога** — транскрипт и результат рядом. Клик по `[n]` у критерия подсвечивает реплику-доказательство. У звонков кнопка ▶ у реплики перематывает запись к ней, есть вкладки «Организаторы» и «Gemini» (повторное распознавание с казахской речью).
3. **Апелляция** — роль «Оператор / супервайзер» → «Оспорить» у критерия. Роль «Проверяющий» → «Рассмотреть апелляцию» → подтвердить или изменить с причиной. Видны исходный балл, решение и итог.
4. **Чек-листы** — критерии, веса, шкалы со ступенями, N/A, флаг грубых ошибок, общие правила оценки. Каждое сохранение — новая версия, её можно сразу применить к набору.

## Результаты для организаторов

```bash
npm run export -- --group DEV       # → results/dev/results.json
npm run export -- --group FBroker   # → results/prod/results.json
```

Файлы в формате 1.0 из приложения к гайду; при выгрузке формат проверяется автоматически.

## Как устроено

| | |
|---|---|
| `public/` | интерфейс на HTML/CSS/JS без сборки, одна точка монтирования — можно встроить в Dynamics 365 |
| `server/` | Node.js + Express: API, загрузка наборов, оценка, апелляции, выгрузка |
| `checklists/default.json` | официальный чек-лист |
| `results/` | выгрузки для организаторов |
| `test/` | тесты подсчёта, проверки ответов модели, выгрузки |

- **Оценка:** Claude Opus 5.5 (`claude-opus-5-5`), ответ строго по JSON-схеме. Контрольные наборы оцениваются тремя прогонами с ответом по большинству.
- **Звонки:** Gemini (`gemini-3.5-flash`) заново распознаёт запись с определением языка и ролей; транскрипт организаторов используется для сверки.
- **Баллы** считает код, а не модель: веса, N/A, ступени шкал, округление до двух знаков.
- Ключи и данные хранятся только локально (`.env`, `data/`) и в репозиторий не попадают.
